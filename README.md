# Issue Tracker Dashboard

A Streamlit dashboard for tracking and visualizing GNOC-India operational issues across multiple categories.

## Features
- **Overall View** — Summary metrics, bar charts, and sheet-wise breakdown
- **Individual Views** — Detailed tables with filters and CSV download for each category:
  - MSDP Issues
  - Autocaller Issues
  - Test Alerts Issues
  - Auto TT Issues
  - ITSM Issues
  - OneFM Issues
  - EtigerNG Issues

## Run Locally
```bash
pip install -r requirements.txt
streamlit run issue_tracker_dashboard.py
```
